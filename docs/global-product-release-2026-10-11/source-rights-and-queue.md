# Source rights and international research queue

Researched October 11, 2026. Imported and published are separate from located, licensed and verified. Source downloads and extraction evidence remain in the private release documentation directory, excluded from the public website.

Imported generic food data: USDA Foundation April 2026, final SR Legacy April 2018 and FNDDS 2021–2023 (October 2024 publication). All are CC0 according to the USDA API/source guidance. The public manifest carries edition, license, retrieval hash, units and import status. Reference dishes are not exact user recipes. Historical named brands are not presented as current menu products.

Refresh procedure: re-fetch an official source, retain its old hash/edition, compare identity/portion/field deltas, quarantine contradictions, inspect changed source columns, rerun market and arithmetic tests, then publish a new record version.
