# Research actually performed

October 4, 2026. Browsing in this release inspected the following live primary pages. Locale was not specified by the search tool; restaurant coverage remains U.S. only. These observations are qualitative, not measured ranking/volume/difficulty data. Earlier user-supplied Search Console photographs are historical context, not a new authorized account export.

| Research query / source | Observation | Implemented decision |
|---|---|---|
| [Google: helpful, reliable, people-first content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content) | Original utility, clarity, reliable sourcing and a satisfying primary purpose matter. A design update is not a reason to invent a fresh data-review date. | The homepage starts meal discovery and shows actual records. Full serving/source explanations remain available on request. No new keyword-variant pages or fabricated review dates. |
| [Google: faceted navigation](https://developers.google.com/crawling/docs/faceted-navigation) | Parameter combinations can create large crawl spaces; canonical signals and deliberate indexing decisions matter. | Preserve the existing finder canonical and curate only existing meaningful reference pages. Shared URLs restore filters without making a new indexable landing page for each combination. No blanket robots change. |
| [Google: JavaScript SEO basics](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics) | Crawlable links, meaningful HTML, canonical metadata and HTTP errors affect discovery. | Shared static meal presentation is generated before enhancement. Restaurant/reference links remain real anchors; homepage quiz links fall back to the finder. Metadata/link gates retained. Actual production status is verified separately. |
| “high protein fast food under 500 calories Chipotle meals”; [primary Chipotle menu announcement](https://newsroom.chipotle.com/2025-12-18-CHIPOTLE-UNVEILS-ITS-FIRST-EVER-HIGH-PROTEIN-MENU-FEATURING-A-NEW-SNACK-READY-HIGH-PROTEIN-CUP) | The inspected results mixed menu announcements, food suggestions and user discussions. Ordering/portion context is essential to a useful answer. The announcement is not a substitute for the repository's separately audited nutrient source. | Preserve the existing under-500 comparison and restaurant guide. New compact results state exact serving, calories and protein, with full nutrients/provenance on request. Do not add new values from an announcement or imply complete current menu coverage. |

`query-to-page.csv` covers all 107 route identities. Its page intents are inferred from existing headings and functionality, not evidence that those exact strings were searched. Applied changes concentrate on clearer task labels, fewer duplicate introductions, readable data, static source content, useful internal navigation, and preserved canonical/indexability settings.

No backlink research, present-day analytics access, revenue forecasting, competitive traffic measurement or paid keyword tool was performed. This work makes no AdSense approval or search-growth promise.
