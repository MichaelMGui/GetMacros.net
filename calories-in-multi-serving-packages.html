Count the package you actually eat

Your shelf

Read per-serving and per-package columns correctly, account for inner packets, and calculate a partial package with clear examples.

In this guide
Outer box versus inner packetFor a partial bag, use the matching weightDo not multiply the whole-package column twice

By GetMacros · Published October 3, 2026

First check whether the calories are listed per serving or per package. If you eat the whole package, use its whole-package column when one is shown. If only per-serving values are available, multiply by the number of servings you eat.

FDA explains that some labels have separate serving and package columns. “One bag” is not enough information until you know which bag the label means.

Outer box versus inner packet

Suppose a box holds four packets. Each packet contains two labeled servings, and each serving lists 110 calories. These are invented values for a packaging example.

Amount eatenLabeled servingsCalories
Half a packet1110
One packet2220
Two packets4440
The outer box8880

The correct multiplier for one packet is two, not four. Four is the number of packets in the box, not the number of servings in the packet.

For a partial bag, use the matching weight

A hypothetical snack label lists 140 calories per 28 g. If you eat 42 g, use 42 ÷ 28 = 1.5 servings, giving 210 calories. Use the same multiplier for each nutrient you want to record.

If the label says “about” a number of servings, multiplying it is an estimate. A gram-based calculation may better describe your measured portion, but it still relies on the label’s rounded nutrient values. Extra decimal places do not turn it into a laboratory measurement.

Do not multiply the whole-package column twice

If a label already says 440 calories per package, do not multiply 440 by the package’s two servings. The serving multiplier has already been included in that column.

  1. Circle the column heading you are using.
  2. Write the amount eaten in the same units as its serving.
  3. Check whether added milk, sauces or other food are included.
  4. Scale that one column once.

Scale carbohydrates to your portion, or compare sodium in two actual portions.
