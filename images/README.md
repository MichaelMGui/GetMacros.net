Reviewed 10 September 2026. This is a maintenance record, not a blanket rights clearance.

- `restaurant-marks/*.svg`: simple initial markers generated by `tools/refine_trust_finish.py`. These use neutral type and colours instead of reproducing restaurant logos. Restaurant names remain visible in the surrounding text.
- `meal-idea-*.svg`: meal illustrations generated by `tools/refine_meal_ideas.py`.
- Inline calculator, plate, book, label, contact and search illustrations: original vector compositions in `tools/refine_colour_system.py`. Colours are defined in `css/colour-system.css` for both themes. These add no image requests.
- `meal-plate.svg`, `meal-play.svg`, the icon sprite and other SVG graphics: local vector artwork used by the site. Their source is available in this repository; local storage alone does not prove ownership.
- Journal graphics, social preview PNGs and app icons: local assets retained. The default social preview was visually checked and is a GetMacros graphic. This review did not independently establish the complete provenance of every older raster file.
- `restaurant-logos/*.png` and `editorial-recipe-portions.webp`: no reuse licence record was found during this review. Published page and quiz references were replaced. The old files remain for historical build compatibility and must not be restored to displayed content without checking their rights.
- Other unused raster files are not made rights-cleared merely by being in this folder. Record their origin and permission before using them.

The final build pass replaces old restaurant-logo references and the recipe illustration's structured-data reference. Keep that pass after the earlier page generators.

Font licence notices are stored separately in `fonts/LICENSE-*.txt`.

For new third-party assets, record the original URL, creator, licence, retrieval date and any attribution requirements here before publishing them.
