# Search intent and workspace review — September 8, 2026

Reviewed page titles and main headings across all 73 pages, plus shared navigation, descriptions, search summaries and repeated paragraph wording. Retained descriptive question-led guides; revised vague tool names and promotional wording. This is a language and information-architecture review, not measured keyword-volume research or a complete medical fact check.

Key changes:
- Meal finder, calculator and search use the same green controls, warm/cool accents and motion system as the rest of the site.
- Search starts with tasks and suggested queries, indexes page content, weights titles, and limits the initial matches to 12.
- Calculator input units and selected states are clear; result details are expandable. Reduced-motion users receive a complete macro chart.
- Replaced unsupported “best” link wording and obsolete references to calorie-range quiz controls.
- Updated nine pages' titles, headings and descriptions. Their existing URLs remain valid.
