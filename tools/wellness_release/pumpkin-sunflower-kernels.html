A weighed ounce of unsalted roasted pumpkin seed kernels has about 156 mg magnesium in USDA reference data, compared with 37 mg for unsalted dry-roasted sunflower kernels. At the same weight, the sunflower entry provides more selenium and folate.

Calculate a mixed topping from the shares you add

If a 28.35 g topping contains half its weight in each kernel, use half of each row. The mix contributes about 96 mg magnesium, 12.6 micrograms selenium and 41.7 micrograms folate. The same ounce does not correspond to the same number of kernels.

Choose kernel entries when the shell is discarded. The values here are USDA reference estimates, and salted or seasoned bags have their own nutrition profiles. In the nutrient explorer, use the same basis for all records before comparing amounts.
