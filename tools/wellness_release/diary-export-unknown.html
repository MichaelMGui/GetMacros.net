In a GetMacros diary backup, a nutrient stored as null means its value was unavailable for that saved food snapshot. A numeric 0 records zero. Keep the distinction if you inspect a backup, copy a field to a spreadsheet, or compare two days.

nullNo protein amount availableKeep it as missing. The known subtotal is 12 g, with one unknown entry.

Keep your backup and analysis apart

Open Diary preferences, then use Export diary in Backup & restore. The downloaded JSON is a restore file that retains individual food entries. For a spreadsheet, copy the values to a separate private file and keep a missing-value column or an explicit “Unknown” label. Summing the known cells can be useful if you also show which values are missing.

Keep the unedited backup to restore through the diary. It can include private notes alongside the entries and stored amounts. See the privacy page for where diary data lives.
