A “prebiotic fiber” claim and the total dietary fiber declaration answer different questions. A total can include fiber from more than one ingredient. The name inulin in an ingredient list can help identify one ingredient, but it does not by itself give the quantity per serving.

The FDA explains which substances can be included in the U.S. dietary fiber declaration. It currently describes enforcement discretion for inulin and inulin-type fructans while rulemaking is pending. The independent scientific consensus on prebiotics additionally asks whether particular microorganisms use the substrate and whether that use benefits the host.

Record the declared fiber and retain the ingredient name if you need it. For a live-microorganism label, use the separate guide to probiotic CFU counts.
