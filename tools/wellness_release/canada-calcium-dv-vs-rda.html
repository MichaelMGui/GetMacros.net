For a general Canadian food label using the 1,300 mg calcium Daily Value, a serving with 260 mg works out to 20% DV. The same serving makes up 26% of a 1,000 mg reference intake. Both percentages can be correct because they divide the same 260 mg by different numbers.

Keep the milligrams when comparing serving sizes

If you eat half of our example serving, the amount drops to 130 mg. That is 10% using the same general label reference. The label percentage is useful for comparing two portions under the same labeling rules. A reference intake adds age and other population assumptions and cannot be inferred from one percentage on a package.

Products intended for young children can use a different labeling reference. For an amount eaten, use the serving size and milligrams printed on the matching package first. Compare foods by their measured calcium per portion.
