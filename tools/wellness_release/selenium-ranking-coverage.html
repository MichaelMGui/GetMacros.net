Reproduce the comparison

Open the explorer, select Selenium, use the 100 g basis and clear the category and search filters. The USDA records for the four table entries are 175139, 173424, 173904 and 171477. Now imagine the first record never made it into the source table. Remove its row and retain all other exact values.

The movement shows why a claim like “highest selenium food” should name its dataset and filters. A zero value would remain a recorded value and appear lower in the sorted list. An absent or unknown value cannot support the same conclusion.
