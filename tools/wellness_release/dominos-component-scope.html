The Domino’s Canada ingredient guide lists amounts for parts of a pizza. In the small hand-tossed section, the pizza sauce value of 5 calories is the sauce for one-sixth of the pie. That small number describes the contribution of sauce to a serving.

Use ingredient records when building an order

A meal filter that excludes components removes the crust and sauce as standalone results. It can still display a finished pizza whose source includes those ingredients. Use the chain’s complete preparation when it is listed. If building a custom estimate, match every part to the same size, crust and fraction before adding it.

The ingredient quantity is distinct from a takeout dipping cup. See GetMacros’ Domino’s Canada menu guide for the coverage and scope of the retained source.
