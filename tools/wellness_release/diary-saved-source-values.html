GetMacros stores the nutrient amounts used when you log food. An entry already saved in your diary continues to use those saved values when the public food catalog changes. A new entry selected from the catalog can use a newer source. The two entries can have the same food name and different figures.

Decide which value describes the original entry

If you need to correct the quantity you ate, editing the old entry uses its saved source basis. If you have a new package with different nutrition, open the new product and check the label before adding another entry. The values above are imaginary. In a real update the package, portion, nutrient fields or source record can change separately.

Missing remains missing

If your older entry has a blank nutrient amount, the new catalog does not silently fill it in. The older daily totals can therefore remain partial. Keep a diary backup if you want a portable copy of the entries and their saved source values.
