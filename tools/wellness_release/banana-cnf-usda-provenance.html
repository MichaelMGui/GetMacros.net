The Canadian Nutrient File’s raw banana entry lists 1.74 g fiber per 100 g, while the USDA’s SR Legacy raw banana entry lists 2.6 g. Both put energy at 89 kcal and potassium at 358 mg for the same edible weight. The Canadian file’s nutrient-specific provenance explains why those figures need not move together.

Health Canada defines source code 0 as unchanged from USDA data. The different fiber source code is a reason to keep the two entries distinct, rather than averaging them or treating the matching potassium numbers as independent tests. Both are reference entries. They do not establish how every banana sold in either country compares.

For a 120 g peeled portion, the two rows scale to about 3.1 g and 2.1 g of fiber respectively. If you report a comparison, retain the food record, dataset release and edible weight so someone else can reproduce it. Explore the USDA reference portion used by GetMacros.
