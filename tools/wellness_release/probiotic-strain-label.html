A probiotic strain code identifies a particular strain within a species. The NIH gives “GG” as the strain code in Lacticaseibacillus rhamnosus GG. Older publications can call it Lactobacillus rhamnosus GG. The change in genus name alone does not indicate a different strain.

Keep the identity check separate from the benefit claim

Even if the strain matches, a study’s preparation, viable count and measured outcome can differ from the package claim. A brand name, a species name and a total number across all strains cannot tell you whether the result applies to the mix. Start with an exact identity match, then compare those other details.
