Check the edible measure before using a piece count

The clam record also gives 190 g for 20 small clams. That named measure would contribute about 122 mcg selenium based on the same reference. It is more than the matched 85 g clam serving because it contains more edible food. If you have a bowl with shells, weigh the edible meat separately when practical.

A different species, breaded preparation, or broth changes the entry. Add the portion of sauce separately if you had it. The diary can store the exact grams for a recurring order.
