Weigh the same package before and after eating, with the lid and other pieces in both weighings. The difference gives the weight removed while the container’s weight cancels out. Subtract any removed food you did not eat.

Worked example using a fictional container
MeasurementWeightInterpretation
Closed tub before eating342 gFood and packaging together
Same closed tub afterward267 gSubtract from the starting weight
Removed food thrown away10 gRemove from the 75 g difference
Amount eaten65 g342 − 267 − 10

Match the result to the grams on the nutrition label

If the label says 120 calories per 80 g, the example is 120 × 65 ÷ 80, or about 98 calories. Do not use the tub’s advertised net weight as your starting scale reading. Net weight describes the declared contents without the package. The two-weighing method depends on using the same package parts both times.

If you drained liquid between weighings or discarded a shell, the scale difference includes that weight. Handle it separately and use an entry for the edible preparation. After weighing, see which label column matches the portion.
