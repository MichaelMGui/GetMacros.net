The percent Daily Value (%DV) tells you how much a serving contributes to a labeling reference. A Tolerable Upper Intake Level (UL) addresses a different question about intake and risk. A vitamin C serving of 1,000 mg represents about 1,111% of the general U.S. label DV of 90 mg.

Read the unit before the percentage

Check the number of capsules or tablets in a serving. Then read the milligrams, add the amount from any other sources when appropriate, and find the separate reference for the nutrient and age group. The upper limit differs by life stage. It is not an intake goal, a guarantee of safety for an individual, or a reason to take an unnecessary supplement.

Use the Supplement Facts serving guide to identify the actual amount. This example uses vitamin C. For some nutrients an upper limit can apply to particular forms or sources, so read that nutrient’s own reference.
