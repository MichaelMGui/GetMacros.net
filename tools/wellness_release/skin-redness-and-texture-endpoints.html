Redness is a color measurement. Surface roughness is a texture measurement. A study can detect a change in either one without measuring the other. If a headline summarizes both as “better skin,” start by checking which property the researchers actually measured.

Check the unit before comparing the size of an effect

A change on a color axis and a change in a surface feature cannot share a meaningful percentage improvement without a separately defined outcome. The smoothie authors also measured yellowness and luminance individually. Even within that one experiment, a redness result does not establish the same result for all other color measurements.
